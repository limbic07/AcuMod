# Acumen MOD Manager

Acumen MOD Manager（Acumod）是一款面向简体中文用户的《怪物猎人：世界 Iceborne》MOD 管理器。当前版本优先提供可靠的传统 MOD 管理功能，采用本地保存、复制启用的方式管理游戏文件。

## 当前功能

- 从文件夹、ZIP、7Z、RAR 导入 MOD，支持拖拽、内嵌压缩包和多分支选择。
- 在本地 MOD 库中启用、禁用、批量操作、卸载和一键还原 MOD。
- 检测已启用 MOD 的文件冲突，并通过优先级排序决定最终覆盖结果。
- 创建和自动识别 MOD 分支组，各分支保留独立启用状态与冲突顺序。
- 按名称、分类、状态、冲突和替换目标检索、筛选及排序 MOD。
- 识别武器、防具、发型、随从装备、飞翔爪、语音、插件等游戏内容。
- 支持武器、防具、发型、随从防具和飞翔爪的模型改绑。
- 从狩技 MOD 盒子导入已有 MOD，并检测游戏目录中的实际启用状态。
- 游戏物品名称可在简体中文和繁體中文之间切换。

## 下载

Windows x64 用户可从 [Releases](https://github.com/limbic07/AcuMod/releases) 下载最新版本，推荐使用 `Acumod_0.1.0_x64-setup.exe` 安装包。

当前发布版本尚未配置代码签名，Windows SmartScreen 可能显示未知发布者提示。
